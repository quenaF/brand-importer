# Changelog

All notable changes to Brand Importer will be documented in this file.

The project follows semantic versioning for published package versions and explicit major-version compatibility for public JSON contracts.

## [0.1.0-rc1] - 2026-08-03

### Added

- Domain-neutral headless import API and canonical runtime-brand compiler
- Ephemeral import sessions with export and disposal semantics
- Truthful progress-event contract
- Import report and session manifest contracts
- Experience Profile and Domain Adapter extension kits
- Host Agent Integration Protocol
- Profile-aware imagery catalog and review planning
- Open Graph, inline SVG, wordmark, and logo-candidate discovery
- Responsive-image deduplication and utility filtering
- Activity, program, people, staff, environment, community, instructional, and product image classification
- Explicit rights safeguards for identifiable people and imagery likely to include minors
- Owner-decision contract and accepted-runtime compilation rules
- Contract compatibility validation
- Cross-brand and cross-profile isolation tests
- Complete architecture, philosophy, API, examples, security, rights, and extension documentation
- Apache License 2.0, contribution guidelines, and contributor code of conduct

### Security and privacy

- Importer sessions retain no organizational memory after disposal
- Example tenants are forbidden as runtime fallbacks
- Imagery requires explicit reuse-rights confirmation before runtime export
- Imported identity remains separate from host-domain workflows and operational data

### Status

Release candidate for independent audit and real-world integration testing. A package-registry release should wait until a reproducible dependency lockfile is committed and the audit findings are resolved.
