# Brand Importer Roadmap

## Phase 0 — Foundation

- [x] Define the product vision and public boundary.
- [x] Create the initial installable skill contract.
- [x] Define v0.1 inputs, outputs, safeguards, and acceptance criteria.
- [x] Establish the fixed evidence-status vocabulary.
- [x] Add the first canonical evidence schema.
- [ ] Add the complete Brand Pack schema.
- [ ] Add design-token and asset-manifest schemas.
- [ ] Add reference guidance for extraction, voice analysis, owner review, and export adapters.

## Phase 1 — First complete import

- [ ] Select a legitimate first dogfood brand with clear authorization.
- [ ] Capture a bounded website evidence set.
- [ ] Produce all canonical Brand Pack files.
- [ ] Generate a CSS theme and Tailwind preset.
- [ ] Apply the Brand Pack to a representative white-label product shell.
- [ ] Run accessibility and provenance checks.
- [ ] Complete an owner-review pass and preserve corrections.

## Phase 2 — Repeatability

- [ ] Add two additional complete examples across different industries.
- [ ] Create deterministic validation fixtures.
- [ ] Add schema validation and export tests.
- [ ] Define source-precedence conflict tests.
- [ ] Add update-mode fixtures that compare two Brand Pack versions.
- [ ] Document installation for Replit Agent, Codex, Claude Code, and Agent Skills-compatible environments.

## Phase 3 — Public v0.1.0

- [ ] Finalize README and installation documentation.
- [ ] Add MIT license and trademark/endorsement language.
- [ ] Add contribution guidance and issue templates.
- [ ] Package the installable skill directory.
- [ ] Publish a versioned GitHub release with downloadable ZIP.
- [ ] Publish to compatible community skill directories.

## Phase 4 — Integrations

- [ ] Figma import adapter.
- [ ] Storybook and design-system adapter.
- [ ] React and Vue theme adapters.
- [ ] Flutter and SwiftUI theme adapters.
- [ ] Shopify, Webflow, and Framer export exploration.
- [ ] Optional documented LumynQ runtime integration.

## Non-goals

Brand Importer will not become:

- a trademark-clearance service;
- an asset-licensing authority;
- a deceptive site-cloning tool;
- a replacement for brand-owner approval;
- a proprietary LumynQ reasoning package;
- a framework-specific theme generator with no canonical source of truth.
