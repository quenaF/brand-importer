# User Becoming

## Primary user

The primary v0.1 user is a developer or AI coding agent preparing a white-label product for an authorized customer.

## They are becoming able to

- onboard a brand without rebuilding its identity from scratch;
- explain why each consequential design or voice decision was made;
- distinguish direct evidence from normalization, interpretation, and owner correction;
- ask the brand owner only the questions that materially affect the result;
- generate multiple implementation targets from one portable source of truth;
- update the white-label product when the brand changes without repeating the entire process.

## They should not be pushed toward

- false certainty;
- copying a brand they are not authorized to use;
- treating frequency as importance without context;
- assuming an attractive result is an accurate result;
- presenting an inferred emotional promise as owner-approved strategy.

## Supporting users

### Brand owner

Becomes able to review and correct the imported identity without needing to understand CSS, tokens, or framework configuration.

### Designer

Becomes able to see the evidence and tradeoffs behind normalized tokens rather than inheriting unexplained automated choices.

### End user

Receives a coherent experience that feels consistent with the organization they intended to engage, without deceptive or inaccessible reproduction.

## Evidence status

This document is **Observed—plan** and contains product hypotheses that must be validated through dogfooding and user review.
